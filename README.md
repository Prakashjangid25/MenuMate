# MenuMate
Online Table Order Food App

MenuMate is a premium, production-ready SaaS platform for Restaurant QR Menu & Ordering, featuring dashboards for platform Super Admins, Restaurant Admins, Kitchen panels, and a seamless checkout experience for customers.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
